# Smart Context Compressor (ST 智能上下文压缩插件)

纯前端实现的 SillyTavern 上下文压缩扩展。在长文本对话中自动提炼角色心理状态与剧情脉络，大幅降低 Token 开销并维持角色与剧情高度连贯。

## 🌟 核心特性

1. **纯前端运行，开箱即用**：
   - 直接复用 SillyTavern 内部大模型接口（`generateRaw`），无需配置或启动任何 Python/Node 后端服务。
2. **长文智能截断**：
   - 默认保留最近 **15 轮**对话（可随时在设置滑块中调节 3~30 轮），其余历史自动截断，杜绝上下文爆仓。
3. **结构化双轨提炼**：
   - **【角色最新状态与关系】**：分析角色在事件中的心境、情绪起伏、对用户的信任/好感演变、关键约定等。
   - **【前情剧情提要】**：提炼关键因果转折与当下未完议题。
4. **两路无损动态注入**：
   - **前情提要**：自动作为 Story Bridge（剧情衔接卡片）注入在截断处头部，承上启下。
   - **角色状态**：无损挂载到角色设定字段（如 `personality` / `scenario` 等），模型发出的瞬间即刻还原，**保证角色卡本体 0 污染、0 残留**。
5. **双触发机制**：
   - **自动触发**：当新增未压缩对白达到设定轮数（默认 10 轮）时，在下次生成前自动发起提炼。
   - **手动触发**：支持在扩展抽屉或聊天工具栏点击“立即执行压缩”随时提炼，并支持随时查看与编辑提炼结果。

## 📁 目录结构

```text
st-context/
├── manifest.json       # 插件清单与拦截器注册
├── index.js            # 核心生命周期、ST 拦截器挂钩
├── compressor.js       # 纯前端模型调用与解析引擎
├── injector.js         # 截断与无损提示词注入模块
├── state.js            # 配置与会话元数据持久化
├── ui.js               # 控制面板、预览微调与交互逻辑
├── style.css           # 界面样式
└── README.md
```

## 🚀 安装方式

1. 将本文件夹复制到 SillyTavern 插件目录：
   `SillyTavern/public/scripts/extensions/third-party/st-context`
2. 刷新 SillyTavern 网页，在右上角「扩展」面板中即可看到「智能上下文压缩器」。
"# sillytavern-context-compressor"
